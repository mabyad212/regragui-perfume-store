# Regragui Perfume — website starter

A responsive, static brand website for Regragui Perfume. Built with plain HTML, CSS and JavaScript for GitHub Pages or Vercel.

## Included
- French, Arabic (RTL) and English language switcher
- Responsive mobile navigation
- Homme / Femme / Unisexe collection filters
- WhatsApp enquiry links configured for `+212 766 384 091`
- Premium black, champagne-gold and ivory visual direction
- No build step or framework required

## Important before publishing
The collection cards are **temporary demo content**, not confirmed products. Replace the sample entries in `script.js` with the actual fragrance names, scent descriptions, stock status and confirmed prices. Confirm delivery fees, payment methods and return policy with the owner.

The current product cards intentionally do not invent prices. 50 ml pricing is marked as a sample presentation until the owner provides the price list.

## Run locally
Open `index.html` in a browser.

## Publish on Vercel
1. Create a GitHub repository named `regragui-perfume-store`.
2. Upload `index.html`, `styles.css`, `script.js` and `README.md` to the repository root.
3. In Vercel, choose **Add New → Project**, import the repository and deploy.
4. Framework preset: **Other**. Build command: leave empty. Output directory: `.`.
